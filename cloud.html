What it does

EPHENYX CLOUD is being developed as a private hosting control plane for EPHENYX bots, APIs and applications. Its current foundation includes owner authentication, tenant-aware storage, environment-secret controls, host registration and resource accounting.

Project focus

  • Private project storage
  • write-only environment secrets
  • host heartbeat and capacity reporting
  • deployment planning around GitHub repositories and pinned commits

Build and workload execution are not enabled yet. A host heartbeat or Docker CLI check does not mean the machine is ready to run deployments. Runtime enablement requires isolation, resource limits, health checks and rollback tests.
