What it does

EPHENYX API is a Node.js service project intended to provide reusable endpoints for selected EPHENYX bot features. The repository includes an API information portal, public metadata search and API-key-protected service routes.

Project focus

  • Public service information
  • bounded metadata search
  • protected song and download routes
  • protected library endpoints and automated checks

The API repository passing automated tests does not mean a public production endpoint is live. Availability depends on deployment, provider terms, rate limits and configured secrets.
